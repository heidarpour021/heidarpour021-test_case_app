# TESTFALLSHANTERING

## Så här kör du programmet

1. Öppna mappen testfall_app i VS Code 
2. Öppna terminalen
3. Skriv python app.py och tryck på Enter


## Huvudmeny (Main Menu)

- **1. Test Case Management** – Öppnar menyn för testfallshantering.
- **0. Exit** – Avslutar programmet.

## Testfallshantering (Test Case Management)

- **1. Add Test Case** – Registrera ett nytt testfall med titel, beskrivning och förväntat resultat.
- **2. List Test Cases** – Visa alla registrerade testfall.
- **0. Back** – Gå tillbaka till huvudmenyn.

## Testfallens ID

Varje registrerat testfall får automatiskt ett unikt ID som börjar med `TC_01`.

Exempel:
- TC_01
- TC_02
- TC_03

## Lagring av testfall

Testfallen sparas i programmets minne medan programmet körs

När programmet avslutas försvinner de registrerade testfallen

Programmet fortsätter att köras tills användaren väljer **0. Exit** i huvudmenyn
